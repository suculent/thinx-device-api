## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Isolation sentinel reset | The execute-phase isolation guard hook reverted to `harness-worktree` between dispatches (the worktree base-check degrades to sequential because origin/HEAD is unresolved). A `gsd-executor` Agent() call without `isolation="worktree"` was then rejected. | advisory | Run `gsd-tools query dispatch-isolation --raw --phase 25 --force-isolation none` immediately before every executor dispatch, and tell executors never to run `dispatch-isolation` themselves. |
| GPG signing without a TTY | Commits are signed (`commit.gpgsign=true`, pinentry loopback). When the gpg-agent cache expired, an executor commit failed with `cannot open /dev/tty`. | advisory | Never bypass signing. Stage the files and return a human-action checkpoint with the exact commit command. The operator commits or warms the cache in a real terminal. |
| Permission classifier on ssh docker exec | A read-only `ssh … 'docker exec -i … node -' < script` probe was denied once and the run stopped correctly. The operator has since allowed the pattern. | advisory | If a command is denied, never route around it. Return a human-action checkpoint with the exact command. |
| `grep -c` in verify chains | 25-03's TELEMETRY-WIRED and EXEMPTION-WIRED used `grep -c` where 0 is the passing value. `grep` exits 1 on 0 matches, so the `&&` chain never printed the marker. | advisory | Add `\|\| true` after `grep -c` in chains where 0 is the pass value, or compare the count explicitly. |
| GPG cache expiry mid-run | 25-05's first commit hit `NEED_PASSPHRASE` after the ~8 h cache expired. The operator unlocked it with `echo unlock \| gpg --clearsign -u 0FCAE40C3C7D6609 >/dev/null`. | advisory | Ask the operator to unlock the agent before a resume that involves commits. |
| Late duplicate agent hand-backs | Earlier executors sometimes delivered stale checkpoint messages after the work had already been done by a continuation, for example "press Build" after the build had finished. | advisory | Check the git log and SUMMARY state before acting on any hand-back. Tell the operator when a message is stale. |
