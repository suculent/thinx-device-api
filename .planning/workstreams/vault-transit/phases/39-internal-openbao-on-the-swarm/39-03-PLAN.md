## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenBao → micro backup | Authenticated snapshot API output becomes a local finalized backup. |
| micro → core | Snapshot and manifest cross restricted SSH; no seal or CA private material crosses. |
| host maintenance → Slack | Sanitized incident state crosses an external webhook boundary. |
| CA files → OpenBao/API trust | Renewed issuer/leaf data must preserve hostname trust through an overlap transaction. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-39-10 | Tampering | Raft snapshot transfer | high | mitigate | Inspect/hash, restricted receiver, pinned host, temp upload, remote verify then atomic finalize. |
| T-39-11 | Information Disclosure | snapshot/alert/log artifacts | high | mitigate | Root-only files, sanitized manifests/reasons, no seal/recovery/CA-private/webhook material. |
| T-39-12 | Spoofing | renewed TLS identity | high | mitigate | Fixed SANs, key/chain/date validation, overlap trust test and served-fingerprint verification. |
| T-39-13 | Repudiation | maintenance incident transitions | medium | mitigate | Durable atomic state and one begin/one recovery receipt with ambiguous-delivery state. |
| T-39-14 | Elevation | restored old credentials | high | mitigate | Isolated rehearsal, rewind warning, post-revocation snapshot requirement and restored-state negative checks. |
