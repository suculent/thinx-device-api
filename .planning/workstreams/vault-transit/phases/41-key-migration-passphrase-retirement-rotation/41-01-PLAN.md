Legacy kinds come from the first line: ENCRYPTED PRIVATE KEY is encrypted_pkcs8, RSA PRIVATE KEY is pkcs1, OPENSSH PRIVATE KEY is openssh, anything else is other. Transit files are counted by their vN prefix. stray_askfiles counts *.sh names, and leftover_tmp counts names matching the keymig temp pattern below.
2. Conversion of an encrypted PKCS#8 file. For each candidate in order, call crypto.createPrivateKey with the PEM text and the candidate value. ERR_OSSL_BAD_DECRYPT means try the next candidate; any other error is cause unparseable; no candidate left is cause wrong_passphrase. Require asymmetricKeyType rsa, otherwise cause unsupported_type. Export type pkcs8, format pem, with no cipher, into a Buffer, and count decrypted_with by the candidate's label.
3. Migrate one file (Pattern 2):
   1. transit.encryptKey(pkcs8Buf), then transit.decryptKey(ct);
   2. require crypto.timingSafeEqual of the two buffers, and that the SPKI of crypto.createPublicKey on the decrypted buffer equals the legacy key's SPKI; otherwise count failed with cause verify_mismatch and write nothing;
   3. zero both buffers in finally;
   4. write ct plus newline to `<sshKeysDir>/.<name>.<crypto.randomBytes(6) hex>.keymig.tmp` through openSync with flag wx and mode 0o600, then writeSync, fsyncSync, closeSync and chmodSync 0o600;
   5. just before renameSync, re-read the target with the bounded read: same sha256, still a regular file, and .pub existence unchanged (keyStillListed when the .pub existed at scan). Otherwise unlink the temp and count changed_during_run;
   6. after the rename, if the .pub existed at scan and is now gone, unlink the private file (a revoke landed mid-rename).
