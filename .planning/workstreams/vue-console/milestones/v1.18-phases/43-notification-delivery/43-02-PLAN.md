<objective>
NOTIF-03: build status frames reach the owner's console sockets. Route every builder notification through the
messenger's per-owner delivery (`sendToOwner`), with the owner bound from the build request, from both the build route
and the queue (D-09, D-12). Since no build frame ever reached a console before (the per-app socket map was never
filled), the frames that start arriving now must follow the UI-SPEC frame rules: one terminal toast per build (F-1),
failures never green (F-2), the terminal frame carries build_id (F-3), no raw log lines (F-4, D-10), owner only (F-5).

Purpose: owners see Pulling repository / Building... / Completed (or the failure reason) in every open Legacy tab.
Output: builder, router and queue changes plus `spec/jasmine/BuilderStatusFramesSpec.js`, a local spec (runs in CI)
that counts the frames each socket receives.
</objective>
