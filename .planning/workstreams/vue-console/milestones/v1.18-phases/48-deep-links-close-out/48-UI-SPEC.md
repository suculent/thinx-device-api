# Phase 48 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope.** The user-visible parts of Phase 48 only. CI-06 and CI-07 (parent and console CircleCI, Cypress harness, `.env.test`) have no visual surface and are not specified here, except where a spec has to assert a contract below.
- Vue console (`services/console/vue`, git submodule):
  - `src/App.vue` (and the `PUBLIC_PATHS` copy in `src/Routes.js`): deep-link reload (NOTIF-04, D-07);
  - `src/pages/Devices/DeviceDetail.vue`: Build Firmware in-flight state (POL-01, D-17) and the width-constrained content column (POL-01, D-18);
  - `src/components/Header/Header.vue` and `Header.scss`: the account menu (POL-01, D-16);
  - `src/pages/Devices/Devices.vue`, `src/styles/_platforms.scss`: view toggles, focusable warning markers, platform sort, checkbox ids (carried Phase 44 items, D-14);
  - `src/styles/_overrides.scss`: `.alert-danger` text contrast (D-14);
  - `src/core/api.js` `parseResult` (35 IN-01, D-12): only its visible consequence in the build log dialog.
- Legacy console (`services/console/src`): copy and message contracts only for D-09 (deploy-key create, the build toast). No Legacy layout or style change.

**Mode.** Autonomous, no user questions. D-01..D-19 in `48-CONTEXT.md` are locked. The visual system, `IconButton`, the 4/8/16/32 spacing, the colour measurements and the copy rules (including "no `text-muted` on content" for every element this phase touches) are inherited from the approved Phase 44 to 47 contracts (`47-UI-SPEC.md`, `46-UI-SPEC.md`, `44-UI-SPEC.md`). Each choice made here is recorded as a `UI-Cnn` decision. The `C` prefix does not collide with Phase 44 `UI-Dnn`, 45 `UI-Knn`, 46 `UI-Tnn` or 47 `UI-Bnn`.

**Out of scope.** These stay as they are:
- the View-log limits (newest 100 builds, no refresh after Build, the list spinner ending on `POST /build`), deferred by D-15;
- a two-column Device Detail redesign (D-18), and the Device Detail `text-muted` key cells and inline `style="width:140px"` (35-UI-REVIEW minor, not POL-01);
- Build Firmware enablement for a device with no source or an unsupported platform (Device Detail keeps today's always-enabled button; the device list already guards both);
- the header search field, the Recent Builds dropdown and the avatar;
- a `?redirect=` return to the deep link after a logged-out reload goes to `/login` (not requested; the login lands on the dashboard as today);
- the theme-wide contrast of `$link-color` `#2477FF` on dark surfaces (3.35:1 on the card), `.btn-primary` white text (4.07:1) and `.badge-info` white text (4.32:1). Phase 47 routed them "next to `.alert-danger`", but D-14 locks only `.alert-danger`; they are listed under Color as known carry-overs for the operator;
- every Legacy layout, every Legacy style and Legacy Cypress.
