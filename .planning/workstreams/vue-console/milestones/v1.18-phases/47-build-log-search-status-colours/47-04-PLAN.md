## Interface contract (used by 47-05)

- `utils/buildLog.js`: `export function hasBuildLog(build)` returns a boolean, true only when `build` is truthy and
  its `build_id` is a string that is not empty (a whitespace-only string counts as an id: the operator's rule is
  "non-empty string").
- Pages register it in `methods` (as History and DeviceDetail register `buildStatusVariant`) and their templates call
  `hasBuildLog(item)` / `hasBuildLog(build)`; script code (`open()`, `rowListeners`) calls the imported function.
- View markup on all three tables: `data-cy="build-open-log" :aria-label="'View build log ' + <row>.build_id"`, visible
  text ` View` after the eye glyph. No-log placeholder on all three tables:
  `<span v-else data-cy="build-no-log"><span aria-hidden="true">—</span><span class="sr-only">No build log</span></span>`.
- History build row (one line): `<tr v-for="(item, i) in filteredBuilds" :key="i" data-cy="build-row" :class="{ 'build-row': hasBuildLog(item) }" v-on="rowListeners(item)">`.
