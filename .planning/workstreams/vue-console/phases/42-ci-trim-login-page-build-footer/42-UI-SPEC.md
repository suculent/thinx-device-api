# Phase 42 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** frontend only, in `services/console/vue`: LOGIN-01, LOGIN-02, LOGIN-03 (Login page) and UI-05 (footers on
Login, PasswordReset and the authenticated Layout). CI-04 / CI-05 (`.circleci/config.yml`) have no UI and no contract here.
Out of scope: the Legacy console, signup routing (the "Create an Account" link still points at `login`, deferred),
the PasswordReset submit buttons' colour, any change to `login()`, the CSRF flow or the OAuth `href`s (D-18).

else is taken from the existing code (Vue 2.6 + bootstrap-vue 2.21.2 + Bootstrap 4.6 + light-blue-vue SCSS in
`src/styles`) and recorded as a decision (`UI-Dnn`) below.

## UI Considerations

Probe: `ui-consideration-probe.cjs` over 5 elements (E1 Login form, E2 Logo, E3 Panel title, E4 Social buttons, E5 Footer),
23 applicable categories, 0 unclassified. Resolved in autonomous mode: 21 explicit, 2 backstop, 0 unresolved, 0 dismissed.
Kind confirmation added `partial` + `populated` to E5 (missing / present build hash), which the prose classifier missed.
Error and empty copy lives in the Copywriting Contract; rows below reference it.

**Explicit (truths):**
- E1 empty: Submitting the Login form with an empty username or password shows "Enter both username and password." in the danger alert; native `required` blocks the request first.
- E1 loading: The Login button gains no new pending/disabled state; `login()` is unchanged (D-18).
- E1 error: Credential, network, server and CSRF failures show the existing Copywriting-Contract messages in the `b-alert` above the Username field.
- E1 partial: Filling only one of Username/Password and submitting shows the same "Enter both username and password." message; no request is sent.
- E1 long-text: A long username or error message wraps inside the panel; the panel never scrolls horizontally.
- E2 empty: If the logo is absent the `alt="THiNX"` text renders in its place and the panel layout is unchanged.
- E2 loading: `width="200" height="100"` on the logo `<img>` reserve its box so the panel does not shift when the image loads.
- E2 populated: The logo renders at 200×100, centred, 24px above the panel.
- E2 overflow: On viewports narrower than 200px plus gutters the logo scales down (`max-width: 100%; height: auto`) and never overflows horizontally.
- E2 long-text: The logo alt text is the single word "THiNX".
- E3 overflow: The panel title never overflows the panel; it wraps.
- E3 long-text: "Welcome to THiNX Management Console." is centred and wraps onto a second line on narrow panels; never truncated or ellipsised.
- E4 empty: Both social buttons always render; their `href`s (`oauthReturnQuery`) are unchanged and never empty.
- E4 loading: Social buttons are plain links with no loading state; clicking navigates to the OAuth provider as today.
- E4 error: OAuth failures keep the existing return-path handling; this phase adds no new social error copy.
- E4 populated: Exactly two social buttons, Google then GitHub, directly under the Login button.
- E4 partial: There is no single-provider variant; both buttons are always present.
- E4 zero-one-many: The social row always holds exactly two buttons; `flex: 1 1 0` gives each half the row.
- E4 long-text: Social labels are fixed strings with `white-space: nowrap`; the 460px stacking breakpoint (UI-D06) guarantees room.
- E5 overflow: The footer wraps at spaces on viewports ≤ 340px; the hash never splits (`white-space: nowrap`); from 800px viewport height the fixed auth footer does not overlap the panel (UI-D10).
- E5 long-text: The footer is one line at ≥ 400px width: `© 2018 – {year} THiNX Console by THiNX Cloud · {hash}`.
- E5 partial: With no valid 7-hex commit id the footer shows no hash and no `·`; with no valid year after 2018 it shows `© 2018` with no range. Never `dev`, `undefined` or an empty span.
- E5 populated: A CI build shows `© 2018 – {UTC build year} THiNX Console by THiNX Cloud · {7-char hash}` on Login, PasswordReset and the authenticated layout.
