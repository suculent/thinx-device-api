## Interface contract (used by 46-03, 46-04 and 46-05)

- `src/utils/transformerUsage.js`: `countDevicesUsing(devices, utids)` returns the number of distinct devices whose
  `transformers` array contains at least one of `utids` (non-array fields count as none); `usageSentence(count, many)`
  returns, for `many` false / true: count 0 `No device uses it.` / `No device uses them.`; 1 `1 device will stop
  applying it.` / `1 device will stop applying them.`; N ≥ 2 `N devices will stop applying it.` / `N devices will stop
  applying them.`; `null` `Devices using this transformer will stop applying it.` / `Devices using these transformers
  will stop applying them.`
- `devices/loadDevices()`: GET /device, commits `saveDevices` like `fetchItems`, throws on a rejected request or a
  `success: false` answer.
- `transformers/deleteItems(utids)`: as stated in must_haves; `transformers/saveTransformers` resolves the POST result,
  plus `refreshed: false` when the POST succeeded but the re-read threw.

  `.button-text`, `.settings-add`, `.dialog-stack`, `.dialog-field`, `.dialog-label`, `.dialog-feedback`,
  `.dialog-help`.
