# Phase 46 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope.** This phase covers the Vue console only (`services/console/vue`):
- the Transformers page `src/pages/Transformers/Transformers.vue` (TRANS-03, TRANS-04, POL-03 delete warning, D-14 naming);
- the Transformer editor `src/pages/Transformers/TransformerEditor.vue` (D-14 naming, the shared leave confirm);
- the Transformer Assignment card on Device Detail `src/pages/Devices/DeviceDetail.vue:108-121` (POL-03 pending and dirty states, 37 IN-02);
- the Environment Globals page `src/pages/Enviros/Enviros.vue` (ENV-01, D-16);
- their stores `src/store/transformers.js`, `src/store/enviros.js` and `src/store/devices.js`;
- `cypress/integration/device-detail.spec.js` (37 IN-03 only).

The parent API fix D-02 (`lib/thinx/apienv.js` exact-key match) has no visual surface. No Legacy (`services/console/src`) change. The `/api/user/env/*` envelopes stay unchanged.

**Mode.** Autonomous, no user questions. D-01..D-16 in `46-CONTEXT.md` are locked; the operator accepted every recommended option. Several things are inherited from the approved Phase 44 and 45 contracts and their fixes:
- the visual system, `IconButton`, the colours (including the `#FF8A8A` field-error text) and the 4/8/16/32 spacing;
- the copy rules (verb + noun buttons in dialogs, no `text-muted` on content);
- the confirm, pending and bulk-toolbar patterns (`44-UI-SPEC.md` UI-D06..UI-D08, UI-D16; `45-UI-SPEC.md` UI-K10..UI-K14);
- the 45-UI-REVIEW lessons: a reload keeps the table rendered, one GET per mutation, the feedback line sits 4px under its field, and the help and feedback lines use weight 400.

The Phase 37 UI review (`.planning/milestones/v1.16-phases/37-transformer-parity/37-UI-REVIEW.md`) and code review (`37-REVIEW.md` IN-02, IN-03) list the problems this phase fixes. Every choice made here is recorded as a `UI-Tnn` decision. The `T` prefix never collides with Phase 44 `UI-Dnn` or Phase 45 `UI-Knn`.

**Out of scope.** These stay as they are:
- the CodeMirror height, font size and theme, and the editor's inline `max-width:400px`;
- the editor title fallback when the name is blank, the editor loading state, and its `hasChanges` flag behaviour (all 37-UI-REVIEW minors not named by POL-03);
- the alias-only create flow on the Transformers page (no body field);
- per-row Delete on Environment Globals (D-16 names bulk delete only);
- reading environment values back (deferred);
- the Device Detail Environment card, the Transfer modal and the device `Alias` field (Device Detail:49 is the device's own alias, not a transformer surface);
- the orange `Manage Transformers` button (operator decision G-37-5, asserted by Cypress);
- the `.alert-*` contrast (theme-wide, Phase 48);
- repairing the Cypress suite (Phase 48 CI-07).
