## Contract shared with 45-02, 45-04 and 45-05

`RSAKey.validateKeyName(name)` (static) returns `{ ok: true }` or `{ ok: false, reason }`:
1. `name` not a string: reason `empty`.
2. Scan every UTF-16 code unit of the untrimmed string from left to right; the first offending unit decides. Code below
   0x20, 0x7F or 0x80..0x9F: `control_chars`. 0x2028 or 0x2029: `line_separator`. 0x202A..0x202E, 0x2066..0x2069, 0x200E
   or 0x200F: `bidi`. The scan runs before trimming because `String.prototype.trim` silently drops a trailing line break
   and U+2028/U+2029.
3. Trimmed string empty: `empty`.
4. Trimmed length (UTF-16 code units, the unit the HTML `maxlength` attribute counts) above 120: `too_long`.
5. Otherwise `{ ok: true }`. Callers trim before storing.

Shared test cases (45-04 mirrors exactly these in the Vue unit test): ok `Firmware 🚀`, `Ünïcödé`, `مفتاح`,
`Firmware Repository`, 120 × `x`; empty `''`, `'   '`, `{}`, `[]`, `42`, `null`, `undefined`; too_long 121 × `x`;
control_chars TAB alone, `a` TAB `b`, `a` DEL `b`, `a` U+0085 `b`, `Firmware` plus a trailing LF; line_separator `a` U+2028
`b`, `a` U+2029 `b`, U+2028 alone; bidi `a` U+202E `b`, `a` U+202A `b`, `a` U+2066 `b`, `a` U+2069 `b`, `a` U+200E `b`,
`a` U+200F `b`.

`PATCH /api/v2/rsakey`, JSON body `{ filename, name }`: 401 (no session, empty body); 403 `csrf_token_invalid` (CSRF
middleware); 400 `invalid_body`; 400 `owner_invalid`; 400 `invalid_filename`; 400 `{success:false,
response:"invalid_key_name", reason}`; 404 `key_not_found`; 500 `rename_failed`; 200 `{success:true, response:<list()
entry>}`.
