# Phase 44 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope.** Vue console only (`services/console/vue`): the Devices page (`src/pages/Devices/Devices.vue`, table and grid
views) for DEV-01..DEV-05, and the Repositories table (`src/pages/Repositories/Repositories.vue` through
`src/components/List/List.vue`) for REPO-01. Two shared components are introduced here and reused by Phases 45–47:
`PlatformBullet` and `IconButton`. No Legacy (`services/console/src`) change and no API change.

**Mode.** Autonomous, no user questions. D-01..D-16 in `44-CONTEXT.md` are locked. Everything else comes from the
existing code (Vue 2.6, bootstrap-vue 2.21.2, Bootstrap 4.6, light-blue-vue SCSS in `src/styles`, Font Awesome 4.7.0)
and from the Legacy reference (`src/app/views/devices.html` :139-191, `src/assets/thinx/css/custom.css` :1-30,
:612-634, :651-659, :882, :895, :993, :1151, `src/app/js/main.js` :168-178). Each choice made here is recorded as a
`UI-Dnn` decision.

**Out of scope.** The bulk Revoke / Transfer / Push Config buttons and their modals, the list/grid view toggles, the
sort and search inputs (only the sort *key* changes, D-12), the Device Detail page, list-load error handling (see UI
Considerations), Repositories columns other than `platform`, and the Cypress specs (Phase 48 CI-07).
