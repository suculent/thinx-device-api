Trace contract (arm specs). Each arm spec keeps an in-memory array of records `{ t, test, ev, win, data }`: `t` is ms
since the spec started, `test` the current test title, `win` the stamped window id or null. At the end it writes them
from an `after` hook with `cy.writeFile('cypress/results/p48-08-trace-<arm>.json', records)`. It writes nothing per
test, so no extra command sits between test 3 and test 4. Required events:
- `test:start` and `test:end`, with data `state`, `duration` and `wallClockDuration`.
- `win:before-load` (stamp `win.__p48 = ++n`, data `href`), `win:load`, `win:before-unload`, `win:unload`, and `url`
  (Cypress url-changed, data `href`).
- `fetch:start`, `fetch:settle` and `fetch:reject`, from a wrapper around the window's `fetch` installed on the window
  before-load event. Data: method, URL path without the query, status or rejection message, and the issuing window id.
- `unhandled`, the window's unhandledrejection: message and the first three stack lines.
- `uncaught`, Cypress's uncaught-exception event: message, first three stack lines and the current window id. The
  handler returns nothing, so Cypress's default behaviour stays in effect.
- `request-log`, from the Cypress request log entries: path, alias or `unmatched`, state.
- `fail`, from Cypress's fail event: message and a `probe` object. The probe holds the AUT `location.href` (or
  `THROWS <error name>`), whether `cy.state('window')` is `cy.state('$autIframe')[0].contentWindow`, the iframe `src`
  attribute, the window's `__p48` and `document.readyState` (each read in its own try/catch). The handler then
  rethrows the error.
