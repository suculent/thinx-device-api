**Status:** ✅ SHIPPED 2026-10-12

## Overview

Make the repo authoritative for the production Traefik edge, migrate it v1-syntax → v2 → v3 (BC mode) → native v3, lock down the dashboard/API, enforce modern TLS and HSTS, and reduce the operational surface (log level, socket-proxy), all without breaking the plaintext legacy device paths and within the deploy SLA. 14/14 requirements; audit `tech_debt` (`v1.15-MILESTONE-AUDIT.md`).

## Milestone Summary

**Key Decisions:**

- Production wins: live edge captured and reconciled into thinx-swarm, which is the only source; the device-api file is a generated read-only mirror (P29).
- Every live edge change is one `docker service update`, repo-first, with a staged one-command rollback; never `docker stack deploy` / `restart.sh` for the edge.
- No public dashboard at all: `api@internal` on a loopback entrypoint reached over ssh + `docker exec` (P33, operator 2026-10-08).
- HSTS/security headers from the file provider (`security-headers@file`) so no label update can drop them (P34).
- SLA budget raised from 300 s to 600 s by the operator on 2026-10-11 (measured 380 s).
- `:7442` and plain MQTT stay plaintext (operator 2026-10-04).

**Issues Deferred:**

- Real client IPs (ingress NAT), then `ipAllowList` / `rateLimit`; `sniStrict=true`; socket-proxy repin trigger.

**Technical Debt Incurred:**

- Fix-forward doc drift, un-dispositioned review ledgers (29/30/32/33), no SECURITY.md for 30/32/34 — see `v1.15-MILESTONE-AUDIT.md`.
