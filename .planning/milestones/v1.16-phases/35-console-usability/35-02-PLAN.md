<objective>
Close UAT gap G-35-4 (UAT test 4, requirement UI-03). The Linked Repository card on the Vue device detail page shows the repository's Git URL as plain text. The operator wants it clickable, opening in a detached tab with `target="_blank"` and `rel="noopener noreferrer"`. Repository URLs are user-entered in the Repositories.vue form and may be `https://…`, an SSH remote such as `git@host:org/repo.git`, or arbitrary text. Binding `:href` naively would turn a stored `javascript:` or `data:` value into a script link (XSS).

Per the orchestrator's gap-closure brief:
- Link the URL only when `new URL(url).protocol` is `http:` or `https:`.
- A parse failure or any other scheme renders as plain text, exactly as today.
- The alias line stays as it is.
- Unit tests cover three cases: an https link with the right target/rel, a javascript: URL with no href, and git@github.com:org/repo.git as plain text.

1. **Tracer (Task 1).** Failing render test, then the computed and the anchor, then signed console commits.
2. **Expansion (Task 2).** Scheme edge-case matrix, the Vue unit files, ESLint on the changed files, then the signed parent gitlink bump. Nothing is pushed.

Purpose: the operator can open the linked repository from the device page in one click, and no stored repository URL can execute script in the console origin.
Output: two console files changed in signed thinx-staging commits, and one signed parent gitlink commit. All of it stays local.
</objective>
