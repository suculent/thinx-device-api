<objective>
Turn statistics back on against InfluxDB 2, which arms the one-way 90-day trim, and clean up the buckets the upgrade carried over.

1. **Tracer (Task 1, read-only).**
   - The production API image reads the migrated history through the v2 client on the real network with equal counts.
   - The drop candidates are proven write-free since the cutover.
2. **Decision (Task 2, blocking-human).** Enable stats and the 90-day trim; drop the empty buckets; approve the Chronograf retirement (executed in 27-07).
3. **Apply (Task 3, one-way).**
   - Mount `INFLUXDB_TOKEN` on thinx_api. The boot ensure adopts `stats/autogen` as `stats` with 90 days.
   - Prove retention, history and a live write.
   - Drop the empty buckets and shred the staged credentials.

Purpose:
- Success criteria 1, 2 (write path) and 4.
- D-01, D-03, D-04, D-10 and D-15.
- OPS-INFLUX-01, OPS-INFLUX-02 and OPS-INFLUX-03.

Output: stats live on InfluxDB 2 with 90-day retention, a clean bucket list, and annex rows.
</objective>

Production conventions: as in the runbook § Conventions. In short:
- **ssh.**
  - `MICRO_SSH` stands for the literal manager ssh command from AGENTS.md § Deployment plus `-o BatchMode=yes -o ConnectTimeout=10`, typed in full, never wrapped or committed.
  - `CORE_SSH` is the `core` entry from `~/.aliases`.
  - A classifier denial becomes a `checkpoint:human-action` with the exact command.
- **Placement.** Query it first. thinx_api placement floats; `docker exec` must run on its node, so if it is on core, rerun the exec via CORE_SSH.
- **Output and waiting.**
  - Aggregates only.
  - No foreground sleep: `timeout 300 docker service update` waits for convergence.
  - Commits GPG-signed; do not push in this plan.
- **CLI one-shots** use `docker run --rm --network thinx_internal --env-file /dev/shm/p27/cli.env --entrypoint influx influxdb:2.9.1 …` on micro.
- **The probe one-shot** before enable (operator token, value via environment only):
  - `IMG=$(docker service inspect thinx_api --format '{{.Spec.TaskTemplate.ContainerSpec.Image}}')`;

- **The probe after enable** runs inside thinx_api with its own mounted token: `docker exec {thinx_api container} node scripts/influx-stats-probe.js …`.
