Production conventions: as in `.planning/runbooks/influxdb2-upgrade.md` § Conventions. In short:
- **ssh.**
  - `MICRO_SSH` stands for the literal manager ssh command in AGENTS.md § Deployment plus `-o BatchMode=yes -o ConnectTimeout=10`. Type it in full in every Bash call; never use a variable, wrapper or committed copy.
  - `CORE_SSH` stands for the `core` entry from `~/.aliases`.
  - If a permission classifier denies an ssh command, return a `checkpoint:human-action` with the exact command; never route around it.
- **Services.** Query placement before `docker exec`, and select containers by `label=com.docker.swarm.service.name=…`. Query services by name.
- **Deploy path.**
  - A thinx-staging push runs CircleCI `test` → `api-registry` (`thinx/api:swarm` in the private registry), plus `console-classic-registry` and `vue-console-registry`. Swarmpit autoredeploys.
  - Check CI with `curl -s 'https://circleci.com/api/v1.1/project/github/suculent/thinx-device-api/tree/thinx-staging?limit=60'`.
  - Push only while no thinx-staging job is queued or running. Never push main; never run restart.sh or a stack deploy.
- **If thinx_api does not roll** within 10 minutes of the api image publish, run no recovery command. Follow the swarm-autopull-recovery skill and return a `checkpoint:decision` carrying its rung-1 command (`docker service update --force swarmpit_app`), or a single `docker service update --with-registry-auth --image {current image name} thinx_api`.

- **Windows.** Outside 01:00–05:00, 06:25–07:10 and 09:25–10:15 UTC, and not after 22:30 UTC. Leave at least 2 hours before 22:30 when the GO is given.
- **Waiting and signing.** No foreground sleep (use a background until-loop or the Monitor tool). Commits GPG-signed; a TTY need becomes a `checkpoint:human-action` with the exact `git commit -S` command.
