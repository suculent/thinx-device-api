Consumed from plan 26-01 (identical contract):
- `paging/audit_by_date`: key = ISO date string, value = doc `_rev`; emits every dated audit doc, including owner-less ones.
- `paging/builds_by_time`: key = epoch ms, value `{owner, udid, build_id, rev}`; `build_id` falls back to `_id`; `udid` may be null for odd docs. It emits nothing for a doc with no numeric time.
