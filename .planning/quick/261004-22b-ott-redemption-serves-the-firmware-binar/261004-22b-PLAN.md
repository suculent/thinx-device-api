# Quick 261004-22b: OTT redemption serves the firmware binary (+ MessengerSpec key leak)

<objective>
Operator decision 2026-10-04: fix OTT redemption now (resuming OTA for auto-update devices with pending builds is accepted).

Root cause (todo `.planning/todos/pending/2026-10-03-ott-redemption-serves-json-not-binary.md`): `fee22323` changed the success branch of `GET /device/firmware` in `lib/router.deviceapi.js` (~line 31) from `Util.respond(res, response.payload)` to `Util.responder(res, response.payload)`. `responder(res, success, message)` JSON-wraps the Buffer, overwrites Content-Type with JSON and leaves Content-Length at the binary size, so ESPhttpUpdate can never flash it.

Additional item (operator): `spec/jasmine/MessengerSpec.js` ~line 101 logs `JSON.stringify(apikey)` (the test owner's MQTT key) and ~line 95 logs the whole `app_config.mqtt` config — stop printing key/config material.
</objective>
